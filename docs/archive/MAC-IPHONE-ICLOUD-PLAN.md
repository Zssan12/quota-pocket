# Mac + iCloud + iPhone 当前方案

> 历史记录，内容对应当时版本，不作为当前安装或支持范围说明。请从[项目首页](../../README.md)开始。

更新：2026-09-15。

唯一数据链路为 Mac 采集 → 字段白名单 → 用户 iCloud Drive → iPhone Scriptable。凭证仅在 Mac。发布范围以此链路为准。

## 本轮实现

- 实验性 LaunchAgent 后台与登录启动管理（文件权限及登录启动仍待实机验收）；禁用时停止当前采集并取消下次登录启动，保留文件。
- 同状态目录单实例锁、正常退出等待正在进行的写入完成、后台日志大小控制。
- 运行版本与磁盘构建标识可比对，更新后通过后台重启加载。
- 未登录不显示假的零账户和默认采集周期。
- 保留明确采集失败状态和原成功时间；iCloud 白名单去掉错误正文。
- Scriptable 次级同步诊断显示读取来源、失败阶段和各阶段时间，支持重新读取。
- 管理页与 README 收敛到唯一 iCloud 引导。

## 验收

用户已确认 iPhone 收到本次真实采集更新。自动化覆盖 Python 采集器、白名单、真实文件导出和已安装 Scriptable 脚本；iOS API 与上游响应使用测试替身。

仍需独立记录：登录重启、Mac 睡眠唤醒、手机蜂窝网络、锁屏、低电量与离线恢复。记录 Mac 采集完成、Mac 文件写入、iPhone 首次读取、桌面重绘四个时间，不能把本机写入时间当作端到端同步耗时。

## 边界

登录后台运行不是开机未登录时运行。Mac 睡眠/关机期间保留旧数据，不阻止睡眠。iCloud 到达和桌面刷新由系统控制。手机重新读取不能唤醒 Mac、强制云同步或立即发起上游查询。
