准备好 Mac 和 iPhone。已完成的步骤会自动识别。

第 1 步 · 在电脑上操作

先连接一个账户

选你正在使用的账户，连接一个就能继续。以后可以随时添加。

连接已有的 CC Switch

先在电脑的 CC Switch 中添加中转账户，并确认它能查到余额。这里会读取已有配置，不需要再粘贴 API Key。

其他工具与高级设置

第 2 步 · 在电脑上操作

确认已经读到真实额度

至少一个账户查询成功就能继续。报错账户可以稍后处理，旧数据不会被当作本次成功。

第 3 步 · 电脑和 iPhone 都需要

用你自己的 iCloud 同步

  1. 两台设备登录同一个 Apple 账户，开启 iCloud 云盘。
  2. iPhone 必须先从 App Store 下载 Scriptable，安装后打开一次，并允许使用 iCloud。
  3. 回到这里点击“启用 iCloud 同步”。

第 4 步 · 在 iPhone 上操作

把额度放到手机桌面

  1. 打开 Scriptable，等待出现这个脚本：点开运行，确认账户与额度出现。
  2. 返回桌面，长按空白处 → 添加小组件 → 搜索 Scriptable。
  3. 选小号（单格）、中号（2 格）或大号（4 格），添加到桌面。
  4. 长按新组件 → 编辑小组件 → Script，选择上面的脚本。

账户选择与排序：在手机脚本中点“调整展示账户”。每个额度窗口都会显示重置时间。

电脑只能确认文件已写入，手机是否收到需要你确认。桌面首次更新可能需要等待。

希望 Mac 登录后自动采集？

这是可选设置。先完成手机显示，再启用后台；如果系统拒绝 iCloud 文件访问，按提示处理权限。

关于自动更新

缓存模式跟随 CC Switch 已有查询；新配置默认每 5 分钟独立查询。iCloud 同步与 iOS 组件刷新由系统调度，不能保证每 5 分钟更新。电脑休眠后保留上次额度，显示原始采集时间。

哪些数据会出现？
